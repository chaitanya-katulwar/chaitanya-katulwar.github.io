Role Lead Motion Designer
Scope Core Interface Motion Specs
Platform iOS, Android & Desktop Web

Overview

Micro-interactions don't get headlines, but they're often the difference between an app that feels premium and one that feels unfinished. At BookMyShow, I owned motion design across the product, not just concepting interactions, but defining specs precise enough for iOS and Android engineers to build them exactly right, sitting with developers separately to get the details correct.

The work includes a search bar with refined state logic and voice input, a parallax amusement parks carousel tested across multiple versions for UX quality, seat selection animations tuned individually for single seats and couch seats, and a tooltip that improved discoverability of the Live Events tab. Small details, deliberately designed.

Process & specs

Motion design is communication, not just decoration. Every spring, friction, and duration constant was specified in detail. Instead of throwing assets over the wall, I sat down with developers individually to tune animation physics in the code itself, ensuring Android spring dynamics felt just as snappy as iOS CoreAnimation variables.

"We translated pure timing curves directly into spring/friction parameters, establishing a unified motion spec sheet for engineer handoffs."

Easing Parameters

Standard animation presets like linear or default ease-in-out make interfaces feel mechanical or sluggish. To establish a premium, responsive feel, I standardized all interface easing curves using a custom cubic-bezier formula: cubic-bezier(0.16, 1, 0.3, 1). This curve features a rapid initial acceleration followed by an extended, gradual deceleration phase.

For layouts involving physical behaviors (such as the amusement park drag carousel), we moved away from time-based curves entirely, implementing spring physics based on mass (1.0), stiffness (140), and damping (18). This prevents animations from feeling robotic, ensuring they respond naturally to dragging gestures.

Tactile Feedback

Motion design is only as good as its performance. Stuttering or dropped frames directly break user immersion. I conducted rendering tests on mid-range Android devices, defining a strict 60fps rendering budget (16.6ms frame budget) for all transition layers.

To achieve this, we forced CSS hardware acceleration using properties like will-change: transform, opacity, ensuring browsers execute animations on the GPU rather than repainting layers on the main CPU thread. I spent hours pair-programming with developers to translate timing specifications into platform-native physics values.

Interactive Premium Feel

Micro-interactions play a key role in guiding users through the page. By focusing on motion patterns and transitions, we enhanced overall usability, directed user attention naturally, and improved the sense of layout flow within the BookMyShow app and website.

Users experienced interfaces that felt responsive and alive, resulting in increased feature discoverability and a premium tactile product feel.
